## Publish as your personal GitHub Pages site

Your GitHub username is `MartinWaffo`. GitHub Pages user sites use a repository named after the account followed by `.github.io`. Because GitHub Pages normalizes the username for the site URL, create the public repository:

`martinwaffo.github.io`

Then upload all files from this folder to the repository root and enable GitHub Pages from the `main` branch if it is not enabled automatically.

Expected site URL:

`https://martinwaffo.github.io/`
