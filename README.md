# Martin Waffo Kemgne — Academic Website

Personal academic website for **Martin Waffo Kemgne**, hosted with GitHub Pages.

The hero uses a lightweight canvas animation to illustrate **dynamic communities, overlap, bridge nodes, and time-stamped interactions**. It has no external JavaScript dependency.

## Update on GitHub
Replace the repository-root files with the files in this folder. In particular, upload `index.html`, `styles.css`, `script.js`, `martin-profile.jpg`, `favicon.svg`, `404.html`, `robots.txt`, and `sitemap.xml`.
